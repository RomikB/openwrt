# Дорожная карта и статус разработки прошивки (Xiaomi BE3600 / RD15)

> **Цель проекта**: Создание надежной, полностью открытой и функциональной прошивки для домашнего роутера Xiaomi BE3600 (RD15) на базе OpenWrt 24 с максимальным использованием аппаратных возможностей SoC Qualcomm IPQ5332.

---

## 1. Текущее состояние проекта

Реализован и всесторонне верифицирован на физическом оборудовании стабильный гибридный стек:
* **Ядро**: Linux 5.4.213 (Qualcomm CodeLinaro QSDK 12.4).
* **Пользовательское окружение**: Нативный OpenWrt 24 (ветка 24.10 / master, Musl libc, GCC 13.3).
* **Сетевой экран**: Современный `firewall4` (`nftables 1.1.x` + `ucode`).
* **Аппаратный оффлоад**: Qualcomm PPE / NSS ECM (Line Rate 2.5 Gbps, загрузка CPU ~0–1%).
* **Беспроводная сеть**: Wi-Fi 6 / 7 Qualcomm Direct Connect (2.4G HE40 + 5G HE160, DFS CAC, `wait_hostapd_sock()`, WPA3 SAE, LuCI интеграция).
* **Свитч**: Открытый драйвер Motorcomm YT9215S на базе официального SDK + открытая утилита `yt-9215s-client`.
* **VPN**: Встроенный протокол AmneziaWG (ядерный модуль `kmod-amneziawg` + CLI `awg` + LuCI UI).

### Параллельные ветки сборок:
1. `xiaomi-rd15-prebuild` — с предсобранным ядром из заводской прошивки.
2. `xiaomi-rd15-qsdk` — с ядром из открытых исходников QSDK 12.4 (FIT-образ `ipq5332-rd15.dts`, нативный `uboot-envtools` и `nvram-env`).

## 2. Аппаратные ограничения хранилища и бюджет Flash

* **`ubi0` (~38 МБ)**: Основной раздел (SquashFS ROM + UBIFS `rootfs_data`).
  * *Правило бюджета:* Суммарный сжатый образ прошивки должен занимать **не более 24–26 МБ**, оставляя не менее 12–14 МБ свободного места под оверлей пользовательских настроек и небольших пакетов.
  * Тяжелые пакеты (`samba4`, `transmission`, Python) не включаются в базовый образ.
* **`ubi1` (~20 МБ)**: Дополнительный пользовательский раздел. Автоматически монтируется в `/data` и используется для установки расширений через `opkg -d data`.

## 3. Важные архитектурные и юридические аспекты

### 3.1. Лицензирование и модель сборки
* Проприетарные компоненты вендора (`qca-firmware`, `qca-hostap`, драйверы Wi-Fi) извлекаются из официальной заводской прошивки Xiaomi скриптом `vendor_scripts/prepare_feed.sh`.
* В репозитории исходного кода хранятся исключительно открытые исходные тексты, Makefiles и патчи. Готовые бинарные сборки с закрытыми компонентами не подлежат распространению в публичных репозиториях во избежание нарушения лицензий Qualcomm/Xiaomi. Применяется классическая модель *«скачай сток и собери сам»*.

### 3.2. Регуляторный домен Wi-Fi (CN BDF)
* Роутер поставляется для рынка Китая. Заводские калибровки в разделах `0:ART` и `0:0:ALL_MISC` жестко оптимизированы под китайский регуляторный домен (`country_code=CN`, `ieee80211d=0`).
* Попытка смены `country_code` на другие регионы может приводить к отказу проприетарного `hostapd` Qualcomm запускать радиомодули из-за несовпадения с BDF-таблицами мощности. Менять параметр следует с осторожностью.
